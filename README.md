# ONE OFF — ひとりだけ、お題が少しちがう

1 台の端末を回して遊ぶ、3〜10 人の会話ゲーム。ひとりだけ少し違うお題を配られた人を（本人も気づいていない）、話のかみ合わなさから見つけ出す。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/one-off/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

3〜10 人。スマホ 1 台を回して、縦画面のタッチだけで遊べる。

1. 端末を回して、ひとりずつ自分のお題をこっそり見る（カードを長押ししている間だけ出る）。
2. みんな同じお題……のはずが、**ひとりだけ少し違うお題**（例: みんなは「うどん」、ひとりだけ「そば」）。違う本人も、自分が違うとは知らない。
3. お題そのものは言わずに、お題について話す（2〜5 分。一時停止・＋1 分あり）。話がかみ合わない人を探そう。
4. 時間が来たら「せーの」で、違うと思う人を指さす。一番多く指された人をタップ。**ワンオフならみんなの勝ち**、違えば **ワンオフの勝ち**。
5. 見つかったワンオフは、最後に **みんなのお題を当てれば逆転勝ち**（設定で切れる）。

- 一番多く指された人が同数で並んだら「同数で並んだ」→ 並んだ人を選んで、その人たちだけでもう一度。それでも同数ならワンオフの逃げ切り。
- 少数派の役は「ワンオフ」、多数派は「みんな」。ワンオフはいつも 1 人。
- お題は 8 ジャンル・200 組。直近に出た 60 組は避けて選ぶ。
- 勝ち数は開いている間だけ数える（閉じたら消える）。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
node test.mjs                 # お題の配り方・投票の決まり・保存データのテスト（フレームワークなし）
```

| ファイル | 中身 |
|---|---|
| `index.html` / `style.css` | 画面の器と見た目 |
| `main.js` | 画面の切り替え・タイマー・音 |
| `logic.js` | お題の配り方、投票（同数・決選・逆転チャンス）、保存データの読み直し |
| `words.js` | お題 200 組 |
| `test.mjs` | `logic.js` と `words.js` のテスト |

保存するもの（localStorage）: `one-off.settings`（プレイヤー名・話す時間・ジャンル・逆転チャンス・音）、`one-off.recent`（直近に出たお題の組）。
